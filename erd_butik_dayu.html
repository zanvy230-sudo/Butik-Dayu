1. Alur Transaksi Sewa Busana Adat

Pengguna memilih produk busana adat, menentukan ukuran & tanggal sewa (mulai dan selesai). Sistem menyimpan status awal menunggu_konfirmasi. Pelanggan mengunggah bukti transfer, dan Admin memverifikasinya menjadi pembayaran_berhasil atau dibatalkan. Setelah pakaian dikembalikan dalam kondisi baik, status menjadi selesai.

2. Alur Booking Jasa Tata Rias (MUA)

Klien memilih paket tata rias (Paket Akad, Resepsi, atau Pre-Wedding), mengisi nama, telepon, alamat lokasi acara, serta waktu (tanggal & jam). Pesanan rias diverifikasi oleh admin dengan memeriksa ketersediaan perias pada jadwal tersebut.

3. Otomasi Notifikasi & Event Model

Setiap kali pesanan baru dibuat atau status pembayaran diperbarui oleh admin, model Eloquent Laravel otomatis menerbitkan notifikasi ke tabel notifikasis yang terhubung ke user_id terkait.

4. Moderasi Ulasan & Testimoni

Ulasan kepuasan layanan yang dikirimkan oleh pengguna tidak langsung tampil ke beranda butik. Admin melakukan moderasi (menunggu → disetujui) dan mengaktifkan tanda ditampilkan = 1 untuk menjaga kredibilitas butik.

⚡ Cara Membuka & Mengedit File di Draw.io (Diagrams.net):

  1. Klik tombol "Download .drawio" di bagian atas halaman ini (atau buka file erd_butik_dayu.drawio di folder project Anda).
  2. Kunjungi situs resmi https://app.diagrams.net di browser Anda.
  3. Pilih "Open Existing Diagram" (atau drag-and-drop file erd_butik_dayu.drawio langsung ke kanvas).
  4. Diagram akan terbuka secara utuh dengan semua elemen (kotak entitas, belah ketupat relasi, oval atribut, teks bergaris bawah PK, dan kardinalitas) yang dapat diedit, digeser, atau diubah warnanya secara bebas!
  5. Untuk menyimpan, pilih menu File > Export as > PNG / PDF / SVG.
